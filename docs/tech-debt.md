## Scope and denominator

- **Scanned:** 23 TypeScript files under `src/` (5,229 lines: `src/core/` 12 files, `src/ui/` 11 files) plus `public/sw.js` (68 lines). `src/config/game-config.json` was read only where code reads it.
- **Method:** full reads of `storage.ts`, `sw.js`, the boot, win, booster, pour-entry and input sections of `main.ts`, the fallback chains in `generator.ts` and `daily.ts`; pattern searches over everything else (TODO/FIXME/HACK/`any`/`@ts-ignore`, `Math.random`, `Date`, `innerHTML`, timers, `??` chains, exported symbols without doc comments, function length). **Not read line by line:** `solver.ts`, `board.ts`, `economy.ts`, `profile.ts`, `audio.ts`, `fx.ts`, `scene-fx.ts`, `shells.ts`, `avatars.ts`, most of `style.css`. Items below say "verify" where I am inferring.
- **Debt markers:** 0 `TODO`, 0 `FIXME`, 0 `HACK`, 0 `@deprecated`, 0 `as any`, 0 `@ts-ignore` in `src/`. The codebase is tidy at the comment level; the debt is structural.
- **Files over 500 lines:** one, `src/ui/main.ts` (1,716 lines, 33% of all source). **Functions over the 40-line standard (main.ts):** `wireInput` 157, `animatePour` 84, `showWin` 63, `renderScenes` 52, `applyStrings` 51, `openCabinet` 49, `renderEdit` 42.
- **Exports without a doc comment:** 2 of about 115 (`AudioOptions` in `src/ui/audio.ts`, `LayerStack` in `src/ui/layers.ts`). `src/core/` public APIs are well documented.
- **Test coverage shape:** `tests/unit/` covers `src/core/`, `storage.ts`, `layout.ts` and `layers.ts`. Nothing imports `main.ts`, so about 1,700 lines (the win flow, boosters, restart/leave state machines, input) have only Playwright screenshots as evidence.

## Checks that found nothing (so nobody repeats them)

- **"main.ts may contain hardcoded gameplay values" hook warning: confirmed a false positive.** Every literal in `main.ts` is presentation: `ANIM` and `NOPE_MS` and `RESTART_CONFIRM_MS` (D31 exemption, documented), toast 2600 ms, hint 2400 ms, class-clear 900 ms, stagger 70 ms and 25 ms, resize debounce 120 ms, theme poll 60 s, burst particle counts and colours, tilt keyframe count 9. All rewards, prices, budgets, caps and thresholds come from `game-config.json` via core functions. One literal is gameplay-adjacent: `PATTERNS = 14` (see TD-11).
- **`innerHTML` use:** every template string interpolates config tokens or SVG from `avatars.ts`/`shells.ts`; player-typed text (profile name) is always set through `textContent`. No injection path found.
- **Save-code import:** wrapped in try/catch, prefix-checked, and re-validated by `loadSave`. `writeSave`/`read` swallow storage errors as designed.
- **`startSceneFx` is idempotent** (returns early when the layer is unchanged), so the 60 s `applyTheme` poll does not restart canvases.
- **Core determinism:** `Math.random` and `Date` appear only in `src/ui/` (fx, audio, name re-roll, shuffle seed, clock reads); `src/core/` takes an RNG or `Date` as a parameter and stays DOM-free.
