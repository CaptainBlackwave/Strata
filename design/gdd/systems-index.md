## Overview

Strata is a phone-first sort puzzle: the player pours layers of sand between jars until every jar is empty or sealed. Around that loop sit a generator that guarantees winnable levels, four jar mechanics, boosters and an economy of coins earned only by playing, a daily puzzle with a streak, a shell collection and four time-of-day scenes. There are eleven systems, all implemented (the player profile was added on 2026-11-08), plus the level map, the badge shelf (sprint 11, D76) and the weekly set (sprint 11, D77).
